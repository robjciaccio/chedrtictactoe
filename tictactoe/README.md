Getting Started
Prerequisites

Before getting started, make sure you have the following installed:

Node.js
npm
Xcode
iOS Simulator

You will also need access to the repository.

Installation

Clone the repository and install dependencies:

git clone <repo-url>
cd <repo-name>
npm install
Running the App

Start the development server:

npm start

Once the terminal is running, press:

i

This will automatically launch the iOS Simulator and start the app.
